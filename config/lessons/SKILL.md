# Lessons for this project

Each lesson is its own file beside this one, read as `skill://lessons/<file>.md`. Its front matter has `title`,
`applies_when`, `date`, `source` and, optionally, `retire_when`; its body is the rule. The index below lists every
lesson as its title and when it applies.

- **Planning:** read every lesson whose "applies when" fits the task, and name in the plan, by title, the ones it relies on.
- **Reviewing:** flag any change that goes against a lesson that applies, citing the lesson.
- A lesson whose `retire_when` has come true no longer applies: say so instead of following it.

## How a lesson is added

Only when he says "make that a lesson", and only for something non-obvious, durable and material. The boss writes it
with its `lesson` tool: one file here and one line in the index below. Threads never edit this folder.

To turn test-first on for this project, he asks the boss to add Jocasta's TDD lesson.
