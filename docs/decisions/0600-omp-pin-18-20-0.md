# 0600 Jocasta moves to omp 18.20.0

- Status: v1
- Kind: product, benchmark
- Phase/slice: program
- Date: 2026-11-14

## Question
Jocasta pins omp 18.18.6 (0589). The installed omp is 18.20.0. Which version does Jocasta pin?

## Facts
Verified 2026-11-14 on the installed omp 18.20.0 (`docs/research/state-of-the-art.md` section 3).
- 18.20.0 is npm's only `latest` tag. It has 615 settings keys against 604 in 18.18.6: 14 added, 3 removed (`task.file` and two `autoRedeem` keys, now per-window keys), no defaults changed. All 55 key paths in Jocasta's shipped files still exist and pass the schema.
- It trims the always-on prompt text by about 3.9 KB (system prompt 3,020 bytes, `read.md` 917 bytes); the rendered token count was not measured.
- Breaking changes that touch Jocasta only if used: `secrets.yml` regexes are Rust `regex` (no lookarounds or backreferences); secret placeholders change form.
- omp#18722 (0598) is fixed since 18.18.8: on the installed 18.20.0, `git --version` with `bash.gitGuard` on exits 0 (it exited 127 on 18.18.6).
- No seam in plan §5.4/5.5 broke in source reading. The collab wire gains one additive `resync` field.

## Options
| Option | Pros | Cons |
|---|---|---|
| 18.20.0 now | Current line; trimmed prompt; git guard fix | Secrets regex change must be checked against his config first |
| Stay on 18.18.6 until his first week of use ends | Nothing moves during the week | Trimmed prompt and fixes wait |
| 18.20.0 after one measured check of the trimmed prompt on a baseline window | Decides on a number | One more measurement first |

## Recommendation
18.20.0 now (option 1), with the secrets regex check done before the bump.

## Choice
omp 18.20.0 everywhere 0589 put 18.18.6: his PC (already installed), the VM before its benchmarks, and every benchmark row (`PINNED_OMP` in `bench/h1-guard/omp-verdicts.ts`). The "checked against" lines in the README, the shipped config files and the benchmark README move with it. The bump lands as its own build slice with its own check.

## Reason
His answer: "18.20.0".

## Consequences
- Amends 0589: the pinned omp is 18.20.0.
- `config/guard.yml`: `bash.gitGuard` returns to `true` once the bump lands and a git run with the guard on exits 0 on Windows; amends 0598.
- Before the bump: the `secrets.yml` regex rules and placeholder form are checked against his config.
- The VM benchmark runs on 18.20.0 (0599).
