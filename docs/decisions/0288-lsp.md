## Question
How does Jarvis get language-server diagnostics?

## Facts
- Checked 2026-10-08 on this machine: `gopls` and `rust-analyzer` are on PATH; `typescript-language-server` and `pyright-langserver` are not. His usage: lsp 11, late diagnostics 12 (appendix A).

## Options
| Option | Pros | Cons |
|---|---|---|
| After edits and on demand, servers already on PATH only | No installs | Missing languages get nothing |
| On demand only | Quieter | Errors found later |
| Jarvis installs missing servers, with his OK | Every language covered | Installs |

## Recommendation
Servers on PATH only.

## Choice
After each edit, the file's language server reports problems in the edit's result, with a short timeout; a `diagnostics` tool checks on demand. When a server is missing, Jarvis offers to install it and installs only with his OK.

## Reason
Not given.

- Differs from the recommendation.
- Amended by 0386: the harness is whole omp with config only; this Jarvis harness piece retires in favor of omp's own.
