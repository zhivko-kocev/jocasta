## For him at the review

The plan's section 6 items, each with the default taken, are repeated here as they are met.

1. **Upstream history against the identity rule** (plan 6.1): taken as a squashed subtree (choice 1), so every push and CI run went ahead. To keep herdr's history instead, the rule would have to exempt the subtree's commits.
2. **herdr's crates in the lock** (plan 6.9): 33 direct crates (27, plus 6 per platform); the lock grows from 389 to 465 packages, the rest already shared with Jocasta. cargo-deny needed four exceptions for them (choice 27: the `0BSD` licence, path crates without a version, and four "unmaintained" notices with no fixed version from herdr's bincode and zbus); no new source. CI's limit is 90 minutes.
3. **`mise.lock`'s Zig entry is hand-written** (choice 5; Zig through mise is his approval of 2026-11-18). Run `mise trust mise.toml` and then `mise lock` once; it should leave `mise.lock` unchanged.
4. **`jocasta worktree list` is herdr's now** (plan 6, finding 18): Jocasta's list of leftover worktrees moved to `jocasta worktree leftover` (changes 0544's word); `jocasta worktree remove <path>` is unchanged.
5. **The trim kept three local parts the plan listed to drop** (choice 13): the release notes, product announcements and onboarding. To drop them later, eight or more of herdr's client-shell files change.
6. **The dock's key and place** (choices 30, 31): Ctrl+B then Alt+T gives `today` his keys; it sits on the right at 35%, in the boss's workspace only; a question shows in the first terminal he attached, 70% by 18 rows. Each is one constant to change.
7. **The HUD's look** (choice 35): it is the tab bar's first right-side segment in herdr's plain status colour; herdr's own `command` segments still work if he wants another beside it.
8. **An old plugin link outside Jocasta** (choice 36): if he still runs a herdr installed apart from Jocasta, `herdr plugin unlink jocasta` there removes the link setup made before the fork.
9. **What the question's reader rule leaves open** (choice 31): a program a pane starts detached (outside the pane's process tree) that attaches as a terminal before his does would read a question, and a terminal whose process the OS doesn't report counts as his. `docs/manual.md` says so beside the guard's other limits. Closing it fully needs a secret only his terminal holds, as 0578's popup had.
10. **The plan signal** (choice 46): the plan poll stays. Moving it into the omp hook needs a plan turn run by a model to verify; the pairing is described in choice 46.
11. **CI fetches Zig's `translate-c` package from codeberg.org on every run** (herdr's vendored `libghostty-vt/build.zig.zon`; CI has no cache, plan finding 33). On 2026-11-18 codeberg's DNS failed and all three runners stopped at the build; a rerun once it answers passes. To remove the dependency, vendor that package's tarball beside `libghostty-vt` and point `build.zig.zon` at the path (about the size of the archive, a new vendored source), or allow a cache action.
